## Core Commands

```sqf
"forge_server" callExtension ["version", []];
"forge_server" callExtension ["status", []];
"forge_server" callExtension ["api:status", []];
"forge_server" callExtension ["persistence:pending", []];
"forge_server" callExtension ["persistence:flush", []];
```

`status` and `api:status` call the API's `/health` endpoint and return
`connected (database: <state>)` or `unavailable: <error>`.
`persistence:pending` returns the number of queued background writes, and
`persistence:flush` waits for them to finish.

## Domain Commands

Game systems should call the domain APIs instead of raw database operations:

- `actor:*`
- `bank:*`
- `garage:*`
- `locker:*`
- `org:*`
- `phone:*`
- `store:*`
- `task:*`
- `cad:*`
- `icom:*`
- `owned:garage:*`
- `owned:locker:*`
- `transport:*`

Large request and response payloads are routed through the transport layer when
needed by `forge_server_addons_extension_fnc_extCall`.
